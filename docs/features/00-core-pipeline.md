# 00 · Базовий конвейєр — `resolve` → `analyze` → `report`

## Що робить
Три команди покривають запит засновника від слів до PDF:

1. **`resolve --topic "<тема будь-якою мовою>" --langs uk,pl,cs`** — через Wikidata (`wbsearchentities` →
   `sitelinks`) знаходить канонічну назву статті в кожному мовному розділі. Мова відсутня → `missing` з
   підказками пошуку в тій вікі, які **не** підставляються автоматично. Інші можливі значення Wikidata
   (омоніми: фільм, журнал, стаття) показуються з підказкою `--qid`.
2. **`analyze`** — за один виклик: ряди переглядів статей (`agent=user`, `all-access`), ряди всього розділу для
   нормалізації, `per_million = views / project_views × 1e6`, тренд, піки, сезонність, YoY, рівень довіри з
   причинами, рейтинг, `chart.png`, `data.csv`, `result.json` і **резюме ≤ 40 рядків**, яке й читає агент.
3. **`report`** — односторінковий A4 PDF (reportlab + шрифт DejaVu з matplotlib): заголовок, таблиця ключових
   чисел, графік, рейтинг, рекомендація агента з `--notes`, футер із припущеннями й обмеженнями
   (українською при `--lang uk`). Завжди одна сторінка: текст рекомендації зменшується й обрізається, футер — ні.

## Ключові рішення й навіщо вони
| Рішення | Навіщо |
|---|---|
| Один конвейєр, а не набір дрібних інструментів | дешева модель (Haiku 4.5) робить 1–3 виклики замість 5–6 і не помиляється у зчепленні |
| Резюме текстом, JSON на диску | контекст агента не роздувається; деталі доступні за потреби |
| Частка уваги «на мільйон», не сирі перегляди | розділи різного розміру стають порівнюваними |
| Ріст на `log(pm+ε)` з вирізаними піками; ε ∝ медіані | тренд не залежить від рівня трафіку (перевірено тестом на 100 / 2 / 0.5 на мільйон) |
| `confidence` high/medium/low + перелік причин | «наскільки можна довіряти» — окреме число, а не інтонація |
| Поточний місяць виключено; закриті місяці кешуються назавжди (з 4-го дня наступного місяця) | повторні запити — секунди; неповні дані не потрапляють у кеш |
| Missing ≠ 0 | відсутня стаття — окремий статус і окреме обмеження у відповіді |
| Сезонність виноситься в Checks | вересневі шкільні піки не порівнюються з липнем |
| Усі падають → рейтинг за обсягом | інакше шкала «ріст × довіра» ставила б на перше місце найменш надійне падіння |

Пороги — в одному місці (`stats.py: THRESHOLDS`) і продубльовані в
[`references/methodology.md`](../../wikipedia-interest/references/methodology.md); тест
`test_methodology_mentions_thresholds` не дасть їм розійтися.

## Як користуватись
```bash
cd wikipedia-interest
uv run scripts/wiki_interest.py resolve --topic "intermittent fasting" --langs pl,cs
uv run scripts/wiki_interest.py analyze --topic "астрономія" --langs uk --months 36 --out runs/astro-uk
uv run scripts/wiki_interest.py report  --run runs/astro-uk --title "Астрономія" --notes "…" --lang uk
```
Готові приклади трьох запитів із завдання: [`examples/`](../../examples/).

## Як перевірено
- 70+ офлайн-тестів (HTTP замокано через respx): кодування назв з `/` і не-ASCII, вікна < 12 місяців, усі мови
  відсутні → exit 2, нульовий ряд без NaN, одна сторінка PDF за будь-якої довжини нотаток, `<title>` у тексті не
  ламає парсер, невідомий код мови → exit 3 з підказкою, лаг публікації місяця не потрапляє в кеш назавжди.
- 3 живих тести (`-m network`) на трьох запитах із завдання.
- Ручна звірка: `data.csv` для «Астрономія» 2025‑03 = 1068 переглядів = пряма відповідь API.
- Прогони на дешевих моделях — див. [06-eval-harness.md](06-eval-harness.md).
